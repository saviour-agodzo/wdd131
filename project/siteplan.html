Website Planning Document

Ghana Cocoa Guide

1. Site Name

CC Ghana Cocoa Guide

Ghana Cocoa Guide is the name of the proposed website. The name clearly identifies the purpose of the site and connects it to Ghana's cocoa industry.

I chose this name because cocoa is an important agricultural product in Ghana. The name is simple, easy to remember, and communicates that the website will provide useful information about cocoa production in Ghana.

Optional domain: ghana-cocoa-guide.org

2. Site Purpose

The purpose of Ghana Cocoa Guide is to provide clear and informative content about cocoa production in Ghana. The website will introduce visitors to cocoa farming, major cocoa-growing regions, the cocoa production process, and the importance of cocoa to Ghana.

The site will use text, photographs, and interactive JavaScript features to make the information easy to understand and engaging for visitors who want to learn more about Ghanaian cocoa.

3. Scenarios

The following questions represent information that visitors to the website may want to find.

Scenario 1

Where are the major cocoa-growing regions in Ghana?

Scenario 2

How is cocoa grown and processed from the farm to the final product?

Scenario 3

Why is cocoa important to Ghana's economy and agriculture?

4. Color Schema

The color scheme is inspired by cocoa farming and the natural environment of Ghana. The selected colors will be used consistently throughout the website.

Forest Green

HEX: #1B4332

Used for the header, navigation, main headings, buttons, and important accents.

Cocoa Brown

HEX: #6F4E37

Used for secondary headings, borders, accents, and cocoa-related design elements.

Cream

HEX: #F5F0E6

Used as a light background color to create a clean and comfortable reading experience.

White

HEX: #FFFFFF

Used for content cards and areas where additional contrast and readability are needed.

5. Typography

Two fonts will be used throughout the website. Poppins will provide strong and clear headings, while Open Sans will make longer paragraphs comfortable to read.

Poppins

Used for the website title, headings, navigation, buttons, and other important labels.

Ghana Cocoa Production

Open Sans

Used for paragraphs, descriptions, instructions, and other body text.

Cocoa farming is an important agricultural activity in Ghana and provides livelihoods for many farmers.

7. Planned Website Features

  • Responsive layout for mobile and desktop screens.
  • Navigation menu for accessing different sections.
  • Images related to cocoa farming and production.
  • Information about cocoa-growing regions in Ghana.
  • Information about the cocoa production process.
  • Interesting cocoa facts.
  • JavaScript interaction to dynamically display information.

8. Project Summary

Ghana Cocoa Guide will be a small informational website designed to help visitors learn about cocoa production in Ghana. The site will combine clear information, photographs, responsive design, and JavaScript interaction to create a useful and engaging experience.
